# Hecatonchires 主入口

日常使用时，双击桌面上的 `Hecatonchires.command`。它会：

1. 检查本机的 Hecatonchires 控制台是否已经运行；
2. 如果已运行，只打开现有页面，不重复启动服务；
3. 如果未运行，启动本地控制台并自动打开浏览器；
4. 保持当前终端窗口运行；在页面右上角点击“退出”会先停用 Live、断开钱包会话，再安全停止本地 UI 服务。

再次使用时直接重新双击同一个 `Hecatonchires.command`。如果页面或终端异常消失后数据库仍
留下非安全状态，下一次启动会先自动执行安全停用；只有确认回到
`PAPER + LIVE_DISABLED` 后才会监听端口。日常不需要启动或累计任何额外验证程序。

Paper 验证阶段仍保留内部专用的三个按钮：

- `1_开始或继续Paper累计验证.command`
- `2_安全暂停并生成报告.command`
- `3_查看进度和打开最新结果.command`

这三个按钮不是日常控制台入口；正式产品只保留 Hecatonchires 主入口，Paper 按钮继续留在
仓库内部用于审计和故障恢复。
主入口默认以 `PAPER + LIVE_DISABLED` 启动；只有在浏览器钱包完成身份签名、生产检查和
用户一键确认后才进入 Live。它不会读取私钥，也不会绕过钱包确认创建真实订单。

运行要求：本机已安装 Node.js `>=24.14.0 <25`，并且仓库依赖已安装。主入口直接启动本地
Node 服务，不依赖 Finder 环境中的 `pnpm` 命令；缺少运行时或依赖时会在终端给出明确提示。
