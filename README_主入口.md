# Hecatonchires 主入口

日常使用时，双击桌面上的 `Hecatonchires.command`。它会：

1. 检查本机的 Hecatonchires 控制台是否已经运行；
2. 如果已运行，只打开现有页面，不重复启动服务；
3. 如果未运行，启动本地控制台并自动打开浏览器；
4. 保持当前终端窗口运行，关闭终端会安全停止这次本地 UI 服务。

当前阶段仍保留 Paper 验证专用的三个按钮：

- `1_开始或继续Paper累计验证.command`
- `2_安全暂停并生成报告.command`
- `3_查看进度和打开最新结果.command`

这三个按钮不是日常控制台入口，后续打包成正式应用时会从用户可见的产品入口中移除。
主入口默认以 `PAPER + LIVE_DISABLED` 启动；只有在浏览器钱包完成身份签名、生产检查和
用户一键确认后才进入 Live。它不会读取私钥，也不会绕过钱包确认创建真实订单。
